The frontend responsibilities are more designed to handle user input.  The frontend is responsible for getting data as well as showing the output of the request data by the user.  The backend is reponsible for housing that information allow the data to be pulled by the user.
the request response lifecycle allows a user to request information and be provided a response from the backend.  Even if the information requested is not available, this is information that can be viewed on the frontend based on the backend output.
